# Reusable Codex startup instructions

Read `AGENTS.md`, `docs/PROJECT_CONTEXT.md`, `docs/CHECKPOINTS.md`, and `docs/CODEX_RECOVERY_PLAYBOOK.md`. Verify checkout: `pwd`, `git status --short --branch`, `git remote -v`, `git log -1 --oneline`. Treat GitHub remote commits as the durable source of truth. Do not reset, clean, overwrite, force push or discard uncommitted changes. Never assume prior application source exists: inspect package.json and the source tree. If only docs are present, report that the app cannot yet run. Do not install app dependencies without a manifest. Always summarize tests performed, commit and push status, and recovery steps for another laptop. Secrets and student reports must never be committed. Do not deploy or enable paid services without approval.
